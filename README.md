"# filme_chucky" 
Sobre o projeto
Este projeto consiste em um site desenvolvido para apresentar informações sobre um dos meus filmes favoritos: Chucky.

O objetivo do site é reunir, de forma simples e organizada, diferentes informações sobre o personagem e sua história, proporcionando uma experiência agradável para quem também é fã do filme.

Conteúdo do site
No site, é possível encontrar:
Sinopse: um resumo sobre a história do filme.
Trailer: vídeo do trailer para conhecer um pouco mais sobre a produção.
 Elenco: informações sobre os principais atores e personagens.
 Curiosidades: fatos interessantes sobre o filme e o personagem Chucky.
 Contato: espaço para os visitantes enviarem opiniões, comentários e sugestões.

 Tecnologias utilizadas
HTML5
CSS3

 Objetivo
O projeto foi desenvolvido com o objetivo de praticar e aprimorar meus conhecimentos em desenvolvimento web, principalmente na criação e organização de páginas utilizando HTML e CSS.
